運動醫學／復健科醫師。把門診常被問到的問題，寫成看得懂的衛教，也做成能互動的小工具。

- 🌐 個人品牌網站：**[sportsmedicine.tw](https://sportsmedicine.tw)** — 運動醫學衛教文章、主題分類與工具集

### 開源專案

| 專案 | 一句話 | 線上 | 原始碼 |
|------|--------|:----:|:------:|
| AI 運動處方 | 依 ACSM FITT-VP 與 WHO 指引產生客製化運動處方 | [開啟](https://exerciseprescription.sportsmedicine.tw/) | [repo](https://github.com/keanu77/exercise-prescription-recommendation) |
| 運動禁藥教育平台 | WADA 禁用清單中文教學、情境測驗、TUE 流程 | [開啟](https://antidopingplatform.sportsmedicine.tw/) | [repo](https://github.com/keanu77/antidoping-platform) |
| 運動醫學 Review 索引 | 系統性回顧、統合分析與臨床指引索引 | [開啟](https://review.sportsmedicine.tw/) | [repo](https://github.com/keanu77/review.sportsmedicine) |
| 台灣運動地圖 | 運動部開放資料視覺化，全台 22 縣市運動現況 | [開啟](https://twexercisemap.sportsmedicine.tw/) | [repo](https://github.com/keanu77/twexercisemap) |
| AthleteType 運動人格 | 28 題情境測驗找出你的運動人格 | [開啟](https://athletetype.sportsmedicine.tw/) | [repo](https://github.com/keanu77/athletetype) |
| 馬拉松完賽訓練 | 2D 橫向跑酷衛教遊戲，管理體力、配速與受傷風險 | [開啟](https://marathongame.sportsmedicine.tw/) | [repo](https://github.com/keanu77/marathongame) |
| 恢復力迷宮 | 原創運動恢復教育迷宮遊戲 | [開啟](https://recoverymaze.sportsmedicine.tw/) | [repo](https://github.com/keanu77/recoverymaze) |

主要用 TypeScript · Astro · Next.js，部署在 Cloudflare。
